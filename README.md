# ReqRes API Testing Project

## Project Overview
This project focuses on testing RESTful APIs using Postman. The ReqRes API is used to practice API testing concepts and validate different HTTP methods, response status codes, response bodies, and API behavior.

## Tools & Technologies
- Postman
- REST API
- JSON
- JavaScript
- Git & GitHub

## API Endpoints & Modules

- **Users:** Get users, get a single user, create, update, and delete users.
- **Login:** Successful and unsuccessful login.
- **Register:** Successful and unsuccessful registration.
- **Resources:** Get resource lists and single resources.
- **Delayed Response:** Test API response behavior with delays.

## Testing Types
- Positive Testing
- Negative Testing
- Functional Testing
- Status Code Validation
- Response Body Validation
- Response Time Validation
- JSON Schema / Data Validation

## HTTP Methods
- GET
- POST
- PUT
- PATCH
- DELETE

## Test Validations
- Verify HTTP status codes.
- Validate response body and JSON data.
- Verify response time.
- Validate required fields.
- Test valid and invalid input data.
- Verify API behavior for different scenarios.
